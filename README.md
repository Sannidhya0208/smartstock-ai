# SmartStock AI

AI-powered Inventory Management System built using

- Angular
- Spring Boot
- PostgreSQL
- Gemini AI
- JWT Authentication
- Docker

- Authentication
- Product Management
- Inventory Tracking
- Supplier Management
- Purchase Orders
- Sales Orders
- Dashboard Analytics
- AI Inventory Assistant
- Natural Language Search
- Stock Prediction
